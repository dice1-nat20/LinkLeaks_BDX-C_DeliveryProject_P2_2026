<h2>Rappels importants</h2>
<p>
    Notre projet a pour but de mettre en place un site qui permet de signaler une fuite d'eau avec une carte interractive (type google map), 
    ajoutant une description et envoyé le signalement qui sera récupéré et stocké dans une base de données. Des études fictives à titre 
    d'exemples pourront être réalisées.
</p>
<p>
    Nous avons utilisé python flask pour lié les données récupérées du site à une base de données.
</p>
